WanderLust
Stay discovery, built as a Java REST API.

A Spring Boot backend for a travel-stay marketplace. It brings together user authentication, host-owned listings, searchable discovery, and guest booking workflows behind a documented REST API.

View source code ↗Run the API / Swagger guide ↗
Java 17Spring Boot 3.5Spring Security + JWTSpring Data JPAMySQL 8DockerOpenAPI

What it does

Core backend capabilities implemented in the repository.

01 / SECURITY

JWT authentication

Registration and login with BCrypt password hashing, signed access tokens, and USER/HOST role rules.

02 / LISTINGS

Search and ownership

Browse listings with location and price filters, pagination, sorting, and host ownership checks on writes.

03 / BOOKINGS

Booking workflows

Guest-scoped reservations with date validation, overlap checks, guest-count constraints, and total-price calculation.

API preview
