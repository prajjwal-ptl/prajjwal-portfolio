# Vikash Mandal — Java Developer Portfolio

A responsive, light-theme portfolio page created as an isolated folder inside the `prajjwal-ptl/prajjwal-portfolio` repository.

## Open the site

When GitHub Pages finishes publishing the latest commit, the page should be available at:

`https://prajjwal-ptl.github.io/prajjwal-portfolio/vikash-mandal-java-portfolio/`

This is a subfolder in the existing portfolio repository, not a standalone repository. Your root portfolio files have not been replaced.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive design, visual components and accessibility rules
- `script.js` — mobile navigation, scroll progress and current year
